# Spec Delta

## Purpose

让用户能在 ADB Helper 面板中开始和停止对选中设备的屏幕录制，并把录制结果保存到本机文件。

## ADDED Requirements

### Requirement: 开始与停止录屏
系统 SHALL 提供显式的开始/停止录屏控件，并向用户展示当前录屏状态。

#### Scenario: 在线设备开始录屏
- **WHEN** 用户选中在线设备并点击开始录屏
- **THEN** 系统开始录制该设备屏幕并把状态显示为录制中

#### Scenario: 用户停止录屏
- **WHEN** 用户在录制中点击停止
- **THEN** 系统结束录制、生成可保存的视频文件并把状态显示为已停止

### Requirement: 保存录屏
系统 SHALL 允许用户在停止录屏后把视频保存到本机文件。

#### Scenario: 用户保存录制文件
- **WHEN** 用户停止录屏并点击保存
- **THEN** 系统通过文件保存对话框写入用户选择的位置

### Requirement: 录屏失败与限制
系统 SHALL 在设备不支持、adb 失败或超过时长上限时给出本地化错误。

#### Scenario: 达到时长上限
- **WHEN** 录屏达到配置的最大时长
- **THEN** 系统自动停止并提示用户已到达上限
